# Accuracy audit — November 10, 2026

The website and CSV now include Ricky Bruno’s **10.95 seconds (+0.0 m/s)** Alvernia 100m performance at the 2013 MAC Outdoor Championships and **21.61 seconds (+0.0 m/s)** 200m performance. Both are documented on his Alvernia TFRRS athlete page: https://tfrrs.org/athletes/4079370/Alvernia/Ricky_Bruno.html.

The 10.80 posted on Ricky Bruno’s World Athletics profile is dated April 14, 2012; the Alvernia TFRRS profile establishes 10.95 as his best *while representing Alvernia*. His West Chester performances after transferring are not included in Alvernia rankings.

The leaderboard code now handles string-valued `false` wind flags correctly. Duplicated record-summary entries with the same athlete, season, year, event and numerical mark no longer inflate the ranking. Wind-aided results identified as such remain excluded.

**Unresolved:** The performance inventory still does not include every Alvernia athlete, event and season from 2009–2026, so these rankings must not be called definitive all-time top tens. Individual field marks and wind documentation still need an exhaustive TFRRS meet-by-meet check. A high placement in the collected data does not automatically make a mark the standing school record.
