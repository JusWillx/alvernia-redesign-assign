# Canvas submission checklist

## Included now
- [x] Working static website and code (`index.html`)
- [x] Completed `TASK.md` with audience, problem, scope and three acceptance criteria
- [x] `AI_USE.md` describing AI work, feedback and human decisions
- [x] `TEST_LOG.md` separating passed, blocked and untested checks
- [x] Earlier-prototype vs current-design screenshots at desktop and 375px phone width
- [x] Sources and research-accuracy limitations
- [x] Demo outline and editable reflection draft

## Still requires student action
- [ ] Record 60–90 second demonstration **or** complete the instructor-approved in-class alternative
- [ ] Personalize reflection and confirm your actual design decisions
- [ ] Share the published website URL **and** repository URL, or obtain instructor approval for ZIP-only submission
- [ ] **Peer test + feedback-driven revision/retest**: omitted at the student's request; still required by the rubric and cannot be marked completed

## Simple publishing route
1. Create a public GitHub repository and upload the contents of this folder (including `index.html`).
2. Open **Settings → Pages** in the repository; select deployment from the `main` branch root and save.
3. Once published, open the resulting Pages address and test the navigation, filters, and source links.
4. Copy the repository URL and live website URL into Canvas.

Do not claim a public URL exists before deployment or a peer test passed without an actual peer.
