# Alvernia Track & Field — Independent student website

A working, responsive HTML/CSS/JavaScript athletics-history prototype using **black, maroon and gold**.

## Open it
Extract the ZIP, then open `index.html` in a browser, or use VS Code's **Live Server** on that file. The website does not need a build step, login, API key or paid service. The downloadable source code is not itself a public website URL.

## Core features
- Men's and women's **School Records**: best collected event marks and separate historical record milestones.
- Men's/women's indoor/outdoor **All-Time Top 10 research**: event, era and unique-athlete filters, with historical source links. The underlying source collection is incomplete and ranking claims are accordingly qualified.
- Search, clear/reset, helpful empty results, featured performances, official roster/schedule links.
- Browser-local demo data editor and CSV import/export. It does **not** change a shared live database.
- Accessible focus indication, labeled inputs, 375px phone support and responsive tables.

## Research limitations
See `PERFORMANCE_DATA.csv`, `RANKED_TOP10_RESEARCH.csv`, `SEASON_COVERAGE.csv`, `TFRRS_METHOD.md`, `LATEST_AUDIT_2026-11-10.md`. TFRRS data and Alvernia Athletics news are sources for the collected marks. The research is not a comprehensive or university-certified all-time record book.

## Sharing
A public site can be hosted on GitHub Pages or another static host; the same folder can be committed to a GitHub repository. If you submit only a ZIP, the rubric requires **instructor approval** for that fallback. A narrated 60–90 second demo and a personalized reflection have not been produced automatically. Peer testing was omitted at the user's request, but the rubric still calls for it.
