# Open and run the working website in VS Code

1. Download and extract the ZIP, then choose **File > Open Folder** in VS Code and select the extracted `alvernia-track` folder.
2. Open `index.html` and right-click in the editor, then select **Open with Live Server** (install the free **Live Server** extension if that menu item does not appear).
3. Your web browser should open a local address such as `http://127.0.0.1:5500/index.html`. Interact with **Records**, **Performances**, **All-Time Top 10**, and **Resources** *in the browser*, not the HTML text editor.
4. The browser's Developer Tools Console (F12) should show no JavaScript errors. If you still see an old page, hard refresh (Ctrl+Shift+R or Cmd+Shift+R) and make sure you opened this extracted folder, not an older ZIP.

This is a local prototype, not a hosted website. Women's all-time rankings and some outdoor archives intentionally show unavailable/empty states until verified. Changes added under Manage Records are local to the current browser only.
